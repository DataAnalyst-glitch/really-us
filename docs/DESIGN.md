# Design
Principle: calm in 5 seconds. Say what not to do first, then the result.

## Surfaces
| Surface | Decision |
|---|---|
| Demo page | Fictional Northline page; one CTA: "Got a message from us? Check it." |
| Widget | Teal and navy; buttons before typing; short replies |
| Trust Console | Top: 4 counts. Left: outbreak card, Approve. Right: live feed. Reset Demo. "Demo data" label |
| Colour | Navy text, teal action, amber check, red for P1 only, always with a text label |
| Our pages | 16 to 18 px text, 44 px targets, short lines, WCAG AA contrast, no charts |

## Verdict copy
```
Don't call or pay yet.
Result: Matches scam signs
1. No disconnection on this account
2. Sent from a personal number
3. Asks you to call that number
Next: Report this sender? [Yes, report] [Talk to a person]
```
Other results: "No matching notice" and "Genuine notice found" (show the official path; never offer a report).

## Writing rules
Plain words, no blame, one question per turn. Never "safe", "guaranteed", "we'll get your money back".
Out of scope: say what the agent can do and offer support; never just list topics.
