## Description (under 150 words; update to match what is built)
Scammers send messages threatening to cut off a customer's power tonight, and customers have no quick way to ask the real company. Really Us? is a customer-support agent that answers one question: is this message really from us? Built on eGain, it checks a pasted message against official guidance and a demo account, then returns one of three verdicts with clear reasons. After explicit confirmation, it reports the sender. When distinct customers report the same sender, a person can approve a warning that shows others the fake pattern. If someone already paid or shared details, it opens a priority case and never promises recovery. Companies can use it to handle impersonation questions and protect customer trust. Its distinctive advantage: only the company can verify its own notices. All data is fictional.
