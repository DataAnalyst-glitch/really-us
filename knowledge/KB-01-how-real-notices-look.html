How real Northline Power notices look

Fictional demo content. Northline Power is a fictional company created for a hackathon demonstration. All contact details are demonstration details.

Summary

A real Northline Power notice comes only through an official channel and includes a Proof Code. Northline never asks you to call a personal mobile number, install an app, or share a one-time password.

What every real notice includes

  • The Northline Power name.
  • The last 4 characters of your demo account reference.
  • A Proof Code in the format NP followed by a hyphen and 4 digits, for example NP-4821.
  • A link only to northline.example, or no link at all.

What a Proof Code is

  • A Proof Code is a short code printed on a real notice. You can give the code to this assistant, and it checks whether that code matches a real notice.
  • A missing or wrong code never proves that a message is real.
  • A valid code confirms that one notice only. It does not reveal account details.

Warning signs

  • The message comes from a personal mobile number.
  • It says your power will be cut today or tonight.
  • It asks you to call or message a mobile number.
  • It asks you to install an app or allow remote access.
  • It asks for a one-time password, card number, or bank login.
  • It sends a shortened link or a site that is not northline.example.

If you are unsure

Do not call, click, or pay yet. Ask this assistant to check the message.
