How to report a suspicious message

Fictional demo content. Northline Power is a fictional company created for a hackathon demonstration. All contact details are demonstration details.

Summary

You can report a suspicious message through this assistant after it checks the message. A report warns other customers only after a Northline team member approves an alert.

How reporting works

  • 1. Paste the message into this assistant.
  • 2. Read the result and the reasons.
  • 3. Choose whether to report the sender.
  • 4. If you confirm, you receive a report reference.

What happens next

If different customers report the same sender, Northline staff review it. If approved, Northline can warn customers about that fake message and explain the real process.

What not to include

Do not share passwords, one-time passwords, card numbers, or bank details in this chat.
